# Provider trim — local-only

**Goal:** Remove all hosted/cloud provider implementation code. Keep `openai-compatible`, `ollama`, `lmstudio` (all use `@ai-sdk/openai-compatible`), and `openai` (`@ai-sdk/openai`). Remove `@ai-sdk/*` deps for all other providers. Remove `@smithy/*` deps (only used by Bedrock event-stream framing). Remove GitHub Copilot product integration.
