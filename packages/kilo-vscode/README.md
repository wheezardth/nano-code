## Key Features

- **Telemetry Disabled:** Nano does not collect or share any data with third parties.
- **Code Generation:** Nano can generate code using natural language.
- **Local Inline Autocomplete:** Get intelligent code completions as you type, powered by local AI models.
- **Task Automation:** Nano can automate repetitive coding tasks to save time..
- **Automated Refactoring:** Nano can refactor and improve existing code efficiently.
- **MCP Server Marketplace**: Nano can easily find, and use MCP servers to extend the agent capabilities.
- **Multi Mode**: Plan with Architect, Code with Coder, and Debug with Debugger, and make your own custom modes.
- **Local AI Models:** Nano supports local AI models for code generation and completion.
- **Customizable:** Nano is highly customizable, allowing users to tailor the experience to their needs.
- **Cross-Platform:** Nano is available on Windows, macOS, and Linux.
- **Open Source:** Nano is open source and available on GitHub.
- **Free and Open Source:** Nano is free and open source, with no hidden fees or subscriptions.
- **No Ads:** Nano has no ads or pop-ups, ensuring a distraction-free coding experience.
- **No Data Collection:** Nano does not collect or share any data with third parties.
- **No Tracking:** Nano does not track your usage or browsing history.
- **No Analytics:** Nano does not collect or share any analytics data with third parties.
- **No Cookies:** Nano does not use cookies to track your browsing history.
- **No Third-Party Services:** Nano does not use any third-party services to track your usage or browsing history.
- **No Third-Party Libraries:** Nano does not use any third-party libraries to track your usage or browsing history.
- **No Third-Party Dependencies:** Nano does not use any third-party dependencies to track your usage or browsing history.
